05 // ML Classification Pipeline

Drone vs. Bird vs. Aircraft

🎯
YOLO-V8 Visual
Fine-tune on synthetic renders from the Blender sim (3000 cams × N frames = massive free training set). Detects drone in motion crop at <15ms/frame on GPU.
📡
RF Fingerprinting
Train CNN on IQ sample time-frequency spectrograms. Identifies drone model from control-link protocol signature — even encrypted packets have timing patterns.
🔊
Rotor Harmonic Match
FFT of beamformed acoustic output. Match against a database of rotor harmonic signatures per drone model. Works 50–200m range.
🌀
Micro-Doppler Analysis
FMCW radar time-frequency analysis of blade flash signature. Distinguishes drone rotor periodicity from bird wingbeats and vehicle vibration.
📊
IMM Trajectory Model
Interacting Multiple Model filter with hover / constant-velocity / coordinated-turn models. Birds follow biological trajectories; drones follow control inputs.
🔗
Fusion Confidence Score
Dempster-Shafer or Bayesian fusion of all classifier outputs into a single 0–1 drone confidence + threat class. Only high-confidence tracks reach Lattice.
06 // Security Hardening (Cyber)

Military Cybersecurity Requirements

🔐
FIPS 140-2 / 140-3
All cryptographic operations through a certified module. AES-256-GCM data at rest. TLS 1.3 with mutual auth for all track data in transit.
🛡
Track Signing + Anti-Spoof
Each CoT/Lattice entity is signed with a sensor private key. Receivers verify signature chain. Injected fake tracks are rejected without a valid HSM signature.
🔒
Zero-Trust Architecture
Each sensor node authenticates to the fusion engine via mTLS + PKI. No implicit trust based on network location. Works over tactical radios and satellite links.
⚡
TEMPEST / EMSEC
Processing hardware in TEMPEST-rated enclosures to prevent EM side-channel leakage. Critical for forward deployed systems near adversary SIGINT assets.
🧱
STIG / SELinux Baseline
OS hardened to DoD STIG profile. Mandatory access control with SELinux. All sensor processes sandboxed. No unnecessary services or open ports.
🌐
GPS Anti-Spoofing + INS Fallback
Cross-validate GPS with visual odometry and IMU dead-reckoning. If GPS deviation > threshold, switch to INS-only ENU mode. Prevents coordinate injection attacks.

08 // Swarm Detection

Coordinated Multi-Drone Attack

CLUSTER TRACK GROUPING
DBSCAN clustering on voxel activations. Treats spatially correlated tracks as a swarm entity with centroid, spread radius, and count.
COORDINATION DETECTION
Graph analysis of inter-drone velocity correlation. Synchronized heading changes → coordinated attack flag. Single drone confusion is different from coherent swarm.
SWARM TRAJECTORY PREDICTION
Predict swarm centroid trajectory 15–30 seconds ahead. Feed predicted intercept point to countermeasure system or alert operator of probable target.
SATURATION ATTACK RESILIENCE
System must maintain ≥50 simultaneous tracks. Priority queue assigns highest threat level to fastest-closing tracks. IMM Kalman scales to N targets.
09 // Resilience + Continuity

GPS-Denied and EW-Contested Ops

VISUAL-INERTIAL ODOMETRY (VIO)
Use camera array + IMU to maintain ENU coordinate frame without GPS. Falls back automatically when GPS deviation or jamming is detected.
RF JAMMING DETECTION
SDR monitors own GPS and communication bands. Sudden AGC rise or SNR drop triggers contested environment mode — reduces reliance on RF sensors.
REDUNDANT COMM PATHS
Track data published over primary LAN → PACE plan: SATCOM → HF radio → offline buffer. Lattice sync resumes automatically when link restores.
GRACEFUL SENSOR DEGRADATION
If any sensor fails, system continues on remaining modalities with increased uncertainty bounds. Pd/Pfa reported dynamically to operator based on active sensors.
