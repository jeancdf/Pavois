# Modèles CAD conservés

- **Support caméra/Pi/IMU** : [camera_mount_v2_pi25.scad](camera_mount_v2_pi25.scad)
  et [STL](camera_mount_v2_pi25.stl). Les accessoires associés sont
  [les entretoises Pi](pi_spacers_pi25.stl) et
  [l’éprouvette d’inserts](tolerance_coupon_pi25.stl).
- **Banc modulaire V5** : [notice et quantités](README_MODULAR_RIG_V05.md),
  [source OpenSCAD](modular_camera_rig_v05.scad),
  [STL et projets Bambu Studio](modular_rig_v05/),
  [archive complète](modular_rig_v05.zip).

Pour trois caméras, imprimer un camera_end_left, un camera_rail central,
un camera_end_right, quatre rails et trois cales. Les supports automatiques
sont configurés dans les 3MF, pas dans les STL.

Les anciennes variantes et les fichiers de comparaison ont été retirés
du dossier ; ils restent disponibles dans l’historique Git.
